# YOLO-projects

YOLO object detection projects.

## Files

| File | Description |
|---|---|
| `YOLO1_v8.ipynb` | Pretrained inference with Ultralytics; YOLOv8n vs YOLO26n on the same image. Includes a from-scratch YOLOv1 backbone. |
| `yolo_notes.md` | How YOLO works, model lineage v1 → YOLO26, cross-generation comparison. |
| `brain_tumor_segmentation_with_YOLOv11.ipynb` | This notebook shows the application of YOLOv11 in segmenting the dead cells in a brain with tumor as done by [Priyadharshini et. al.](https://doi.org/10.1038/s41598-025-13155-4) |
